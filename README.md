##  About MotionLab

MotionLab is an interactive animation playground built with **React, TypeScript, and Motion**.

The project provides a collection of interactive animation experiments that allow users to explore different animation concepts including entrance animations, gestures, scroll-based animations, spring physics, layout transitions, shared element animations, text animations, transitions, and advanced motion techniques.

It also includes an interactive **Animation Playground** and **Timeline Builder**, allowing users to experiment with animation properties, visualize animation sequences, and generate reusable Motion animation code.

#  Installation

## 1. Clone the repository

git clone https://github.com/abhigyan-oss/motionlab.git

## 2. Navigate to the project directory

cd motionlab

## 3. Install dependencies

npm install

## 4. Start the development server

npm run dev

The application will be available at:

http://localhost:5173

---

#  Build for Production

To create an optimized production build:

npm run build

To preview the production build locally:

npm run preview

#  Why MotionLab?

MotionLab was built as more than just an animation demo.

The goal was to create an interactive environment where developers can:

- Learn animation concepts visually
- Experiment with Motion properties
- Understand spring physics
- Test different transitions
- Build animation sequences
- Generate reusable animation code

This makes MotionLab both a **learning platform** and an **interactive developer tool**.
